Tool Gateway 与权限引擎

1. 概述

Tool Gateway 是 Agent 工具调用的唯一入口，所有工具调用必须经过：
Schema 校验 → 权限分级 → 命令分类 → 执行 → 记账。

2. 核心组件

2.1 Tool Gateway

  • 注册所有工具（command/write/skill/terminal 系列）。
  • 统一执行入口 executeCall。
  • 每个调用生成 tool_calls 记录。

2.2 Permission Engine

风险分级：

级别含义典型工具
R0只读，无风险list, wait, load_skill
R1低风险，可能泄露信息read, terminal.read
R2中风险，可能修改状态create, send (shell), terminal.create
R3高风险，不可逆操作kill, terminal.kill
R4前置拒绝任何被策略禁止的操作

2.3 Command Classifier

对注入文本进行动态分类：

  • 裸 shell 注入 → 命令执行，最低 R2。
  • TUI/Agent 注入 → 内容注入，R1。
  • 控制字符（^C）→ R2。

3. 工具注册模式

text
registerTerminalTools(gateway)
registerCommandTools(gateway)
registerWriteTools(gateway)
registerSkillTools(gateway)

每个工具包含：

  • name: 工具名称
  • description: 描述（注入模型提示）
  • inputSchema: JSON Schema 校验
  • riskLevel: 默认风险级别
  • handler: 执行函数

4. 审批流程

4.1 单次审批

  1. 工具调用到达 Gateway。
  2. 分类器确定风险级别。
  3. 高风险调用创建 permission_request。
  4. UI 在多个入口渲染（rail badge, fleet tile, room card, notification）。
  5. 用户在任何入口解决，所有入口同步清除。

4.2 长期规则

"Always allow for this task" 实现为 StandingRule，
作用域：(task, tool, target terminal)。

5. 特殊工具：load_skill

  • R0 只读，各模式可用。
  • 从托管库读 SKILL.md 或打包引用文件。
  • 路径穿越拒绝。
  • 每次加载进 tool audit 与任务时间线。

6. 终端编排工具

6.1 六个原语

工具风险说明
terminal.listR0列出可见兄弟终端
terminal.readR1读取终端输出
terminal.send动态注入文本
terminal.createR2创建新终端
terminal.waitR0等待完成
terminal.killR3关闭终端

6.2 动态风险

send 的风险根据目标前台进程动态确定：

  • 裸 shell → R2（命令执行）
  • TUI/Agent → R1（内容注入）
  • 控制字符 → R2

6.3 深度限制

  • 编排深度限制 2 层（orchestrator → worker）。
  • Worker 不能再创建 worker。
  • 主机端强制，非 skill 散文。

7. 预算与暂停

  • 每 orchestrator 预算：≤5 活 worker，≤30 sends/min。
  • 两档暂停：per-worker "pause remote control"，fleet-wide "pause all"。
  • 暂停只排队新注入，不中断运行中命令。
  • 用户键盘输入 = takeover，队列自动保持。

8. 记账策略

  • 所有调用入 tool_calls，含调用者身份。
  • send 注入文本完整记录（已过分类）。
  • read/wait 只记元数据（target, line/byte counts, completion reason）。
  • 捕获的输出不持久化（兄弟终端可能显示 secrets）。

9. Rust 实现要点

rust
// 工具注册
struct ToolGateway {
    tools: HashMap<String, Box<dyn Tool>>,
    permission_engine: Arc<PermissionEngine>,
    ledger: Arc<Ledger>,
}

#[async_trait]
trait Tool {
    fn name(&self) -> &str;
    fn risk_level(&self) -> RiskLevel;
    async fn execute(&self, input: Value, ctx: &CallContext) -> Result<ToolResult, ToolError>;
}

// 权限检查
enum RiskLevel {
    R0, R1, R2, R3, R4,
}

struct PermissionEngine {
    standing_rules: Vec<StandingRule>,
    budget_tracker: BudgetTracker,
}
