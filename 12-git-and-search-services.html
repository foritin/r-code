Git 与搜索服务

1. Git 服务

1.1 概述

Git 服务提供仓库检测、状态查询、差异比较、暂存/取消暂存、
丢弃、提交、分支切换等能力。

1.2 当前实现

  • 使用 Node git 库。
  • 提供 detect/status/diff/stage/unstage/discard/commit/branch 操作。

1.3 Rust 替代

  • 使用 git2 crate（libgit2 绑定）。
  • 异步封装避免阻塞。

1.4 核心能力

能力说明
detect检测目录是否为 git 仓库
status获取工作区状态（porcelain v2 格式）
diff获取文件差异
stage暂存文件
unstage取消暂存
discard丢弃更改（需确认）
commit提交
branch分支切换/创建/删除
worktreeworktree 管理

1.5 Worktree 隔离

text
git worktree add -b charter/<taskId> <userData>/worktrees/<wsId>/<taskId> HEAD
  • 每任务独立 worktree
  • 合并回主分支在归档时或显式操作时

1.6 快照机制

bash
# 创建临时索引
GIT_INDEX_FILE=$(mktemp) git add -A

1.7 Rust 实现要点

rust
use git2::{Repository, StatusOptions, DiffOptions};

struct GitService {
    repo: Repository,
}

impl GitService {
    fn detect(path: &Path) -> bool {
        Repository::discover(path).is_ok()
    }
    
    fn status(&self) -> Result<Vec<GitStatus>, GitError> {
        let mut opts = StatusOptions::new();
        opts.include_untracked(true);
        let statuses = self.repo.statuses(Some(&mut opts))?;
        // 转换为内部 GitStatus
    }
    
    fn diff(&self, path: &Path) -> Result<Diff, GitError> {
        let mut opts = DiffOptions::new();
        opts.pathspec(path);
        let diff = self.repo.diff_index_to_workdir(None, Some(&mut opts))?;
        Ok(Diff::from(diff))
    }
    
    fn stage(&self, paths: &[PathBuf]) -> Result<(), GitError> {
        let mut index = self.repo.index()?;
        for path in paths {
            index.add_path(path)?;
        }
        index.write()?;
        Ok(())
    }
    
    fn commit(&self, message: &str, author: &Signature) -> Result<Oid, GitError> {
        let mut index = self.repo.index()?;
        let tree_id = index.write_tree()?;
        let tree = self.repo.find_tree(tree_id)?;
        let parent = self.repo.head()?.peel_to_commit()?;
        let signature = Signature::now(author.name(), author.email())?;
        let oid = self.repo.commit(
            Some("HEAD"),
            &signature,
            &signature,
            message,
            &tree,
            &[&parent],
        )?;
        Ok(oid)
    }
}

2. 搜索服务

2.1 概述

搜索服务提供 Quick Open（快速打开文件）和全局搜索能力。
支持正则、大小写敏感、文件包含/排除。

2.2 当前实现

  • 解析顺序：env 覆盖 → @vscode/ripgrep 二进制 → 系统 PATH 中的 rg → JS 兜底扫描器。
  • Quick Open 服务侧 fuzzy + 最近文件提升。
  • 全局搜索：rg candidates + JS offsets 引擎，支持取消。

2.3 Rust 替代

  • 直接调用 rg 二进制（已是 Rust）。
  • 或使用 grep-matcher + grep-regex + grep-searcher crates 自行实现。

2.4 Quick Open

  • 服务侧模糊匹配。
  • 最近文件提升。
  • 首批 2000 条，p95 ≤ 300ms。

2.5 全局搜索

  • 首批 200 条，p95 ≤ 1s。
  • 可取消：pre-aborted 在 <1ms 内返回。
  • 超大文件跳过（per-file cap）。

struct SearchService {

struct SearchOptions {

    path: PathBuf,
    case_sensitive: bool,
    regex: bool,
    include_glob: Option<String>,
    exclude_glob: Option<String>,
    max_results: usize,
}

struct SearchResult {
    path: PathBuf,
    line_number: Option<u64>,
    column: Option<u64>,
    text: String,
    context_before: Vec<String>,
    context_after: Vec<String>,
}

impl SearchService {
    fn search(&self, opts: SearchOptions, cancel: &CancellationToken) -> Result<Vec<SearchResult>, SearchError> {
        let output = Command::new(&self.rg_path)
            .arg("--json")
            .arg("--line-number")
            .arg("--column")
            .arg(if opts.case_sensitive { "--case-sensitive" } else { "--ignore-case" })
            .arg("--glob")
            .arg(opts.include_glob.as_deref().unwrap_or("*"))
            .arg("--glob")
            .arg(format!("!{}", opts.exclude_glob.as_deref().unwrap_or("")))
            .arg(&opts.pattern)
            .arg(&opts.path)
            .output()?;
        
        // 解析 JSON 输出
        self.parse_results(&output.stdout)
    }

3. ChangeService

3.1 概述

ChangeService 管理文件基线和变更记录，支持任务级净 Diff 投影和回滚。

3.2 核心概念

  • BlobStore：内容寻址 blob 存储，去重。
  • FileBaseline：文件基线，capture-once。
  • FileChange：文件变更记录（create/modify/delete/rename）。
  • ChangeSet：任务级净 Diff 投影。

3.3 变更检测

  • 中间补丁折叠。
  • 净效果计算。

3.4 回滚引擎

  • 创建/修改/删除/重命名。
  • 预检外部变更冲突。
  • byte-exact 恢复。

// 内容寻址 Blob
struct BlobStore {
    db: Arc<Database>,
    blobs_dir: PathBuf,
}

impl BlobStore {
    fn put(&self, content: &[u8]) -> Result<String, BlobError> {
        let hash = blake3::hash(content).to_hex().to_string();
        // 去重
        if self.exists(&hash)? {
            self.increment_ref(&hash)?;
        } else {
            self.write_blob(&hash, content)?;
        }
        Ok(hash)
    }
    
    fn get(&self, hash: &str) -> Result<Vec<u8>, BlobError> {
        let path = self.blobs_dir.join(hash);
        Ok(std::fs::read(path)?)
    }
}
