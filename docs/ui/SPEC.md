# R-Code 任务房间与右侧工作台规范

状态：当前有效
视觉方向：安静、克制、专业；暖白 / 暖炭黑表面，橘色只承担选择、运行提示和主操作。

## 核心结构

任务页由“项目导航 + 主对话 + 可停靠工作台”组成。右侧工作台不是全局检查器，也不是固定窄栏：

- 关闭时完全释放空间，主对话恢复完整宽度。
- 打开后约占窗口 40–42%，同一时刻只承载一种工具。
- 顶部标签承载运行、终端、文件和审核；切换工具原子替换，不叠第二条侧栏。
- 启动器是临时入口；关闭最后一个工具后回到启动器，隐藏工作台后不保留空白轨。
- 待处理审核可以收起成同一份审核摘要窄轨；再次展开必须恢复原 task、文件和滚动位置，不能变成项目动态。

## 工作台状态

1. **运行 / 子代理**：列表显示名称、任务、状态和耗时；点击后展示公开活动、当前动作与结果。停止子代理和关闭面板是两个动作。
2. **终端**：终端表面直接铺满画布。隐藏面板不结束 PTY；“结束终端”必须明确确认。
3. **文件**：任务内默认只读 Peek，中央文件内容、右侧项目树；“在编辑器打开”才离开任务页。
4. **审核**：变更列表、所选 diff、变更树与决策栏共同使用宽工作台；详细内容不足时进入 Focus 模式，不压成 340px 小窗。
5. **审核收起**：只保留审核图标、未决数量和状态；展开后恢复同一审核摘要。

每个项目和任务分别保存工作台状态。切换任务时不得泄漏上一个任务的文件、终端、审核或子代理选择。后台完成事件只更新徽标或通知，不能抢走当前视图。

## 任务运行的渐进披露

主对话内只保留三层信息：

1. **摘要**：当前动作、运行状态、步骤数量或耗时。
2. **活动**：整理过的人类可读步骤。
3. **详情**：点击具体活动后才展示命令、耗时、退出状态与公开输出。

普通界面禁止显示 `tool_call`、`subagent_lifecycle`、`delegate_task`、`collect_subagents`、原始 JSON、内部 ID、队列协议、生命周期日志和私有推理。开发者诊断必须显式打开。

## 视觉约束

- 主内容使用连续平面、留白和 1px 分隔线，不使用卡片套卡片。
- 工作台主背景、编辑区、终端、diff、文件树不再套第二层圆角容器。
- 活动行默认透明；Hover 只增加轻微表面色，不位移、不发光。
- 圆角只使用 `4 / 6 / 8 / 12px` 四档：状态标签 4px、列表与轻量容器 6px、按钮与输入框 8px、Composer 12px。
- 暗色表面依次为 `#151311 / #181715 / #211F1C / #282521`；亮色为 `#FBFAF7 / #FFFEFC / #F7F3ED`。
- 橘色不用于大面积背景。成功、警告、删除和新增继续使用各自语义色。
- 正文使用 UI 无衬线字体；命令、路径、耗时与状态码使用等宽字体。
- 文件树每层缩进 `16px`，选中行使用中性底色加 2px 橘色标记，不铺满橘色。
- Diff 代码不换行；新增、删除分别使用绿、红语义，品牌橘色不替代 diff 语义。

## 响应式与交互

- `1440px+`：右侧 Dock。
- `1180–1439px`：允许工作台适度缩窄，但主对话输入区不可被压坏。
- `1024–1179px`：工作台改为覆盖或 Focus 布局，不把对话和代码各压成窄条。
- 所有展开控件同步 `aria-expanded`；标签使用 `aria-selected`。
- 启动器支持方向键、Enter、Esc，并在关闭后归还原焦点。
- 工作台切换保留各工具的选中项和滚动位置；重新打开前先校验终端、文件等外部状态仍存在。
- 系统启用“减少动态效果”时停用呼吸动画；颜色不是唯一状态提示。

## 当前原型与 Demo

`prototypes/workbench/` 的 12 张 `1600 × 1000px` 图片是工作台方向的视觉参考，覆盖启动器、运行与子代理、终端、文件、审核和审核收起的亮/暗主题。

当前 `demo/` 直接打包正式 React 前端，覆盖完整应用场景与任务级工作台四工具；`demo/qa.cjs` 将验收截图写入 `target/ui-demo/`，不会覆盖参考图片。
