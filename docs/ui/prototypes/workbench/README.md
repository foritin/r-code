# R-Code 工作台原型图

这 12 张图全部由 `../../demo/index.html` 的同一份交互实现生成，尺寸固定为 `1600 × 1000px`。

| 编号 | 状态 | 主题 |
| --- | --- | --- |
| 01 / 02 | 工作台启动器 | 亮色 / 暗色 |
| 03 / 04 | 运行与子代理详情 | 亮色 / 暗色 |
| 05 / 06 | 集成终端 | 亮色 / 暗色 |
| 07 / 08 | 文件 Peek 与项目树 | 亮色 / 暗色 |
| 09 / 10 | 审核、Diff 与变更树 | 亮色 / 暗色 |
| 11 / 12 | 审核摘要收起 | 亮色 / 暗色 |

不要手工修改 PNG。需要更新时运行：

```powershell
node ../../demo/qa.cjs --visual-only --update-prototypes
```

渲染脚本会先执行双主题与多视口布局审计；失败时不会把问题当作已通过的交付结果。
