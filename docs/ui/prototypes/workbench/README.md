## 会话操作规则

- 鼠标未悬停时不显示操作；键盘聚焦时仍可访问。
- 悬停后只显示“置顶”和“归档”两个内联图标，不使用三点菜单。
- 置顶直接切换，并把会话移动到当前项目顶部。
- 归档单击即执行，不弹确认框。
- 原型不提供“永久删除”入口或确认层。

## 主交互信息流

主对话采用连续阅读布局，减少卡片、描边和重复状态容器：

- 用户消息保留一个轻量气泡；Agent 输出不再套卡片。
- Agent 回答与命令、文件编辑、上下文压缩、子智能体等事件按真实发生顺序交替排列。
- 执行中每个命令批次默认只显示一行摘要；多命令默认显示最上层“运行了多个命令”，展开后才显示子命令。长清单限制在固定高度内独立滚动，不挤压后续回答。
- 完成后显示灰色“已处理 + 时间”；它只折叠过程记录，不会隐藏最终回答、输出文件和完成操作。
- 解释、判断和最终结果使用正常高对比正文。
- 已执行命令使用弱化文字与终端图标，保持可追溯但不抢阅读焦点。
- 静态 PNG 只用灰色当前命令表达执行中，不模拟字符流光。字符流光留给后续交互 Demo：浅灰字符从左到右过渡为正常色，并为“减少动态效果”提供静态退化。
- “上下文已自动压缩”是不可展开的扁平系统事件；子智能体以状态胶囊出现，点击后进入右侧子智能体页。
- 多命令、单 Shell 与单文件 diff 只有用户主动展开后才使用卡片承载详情。
- 最终输出存在文件时，以带文件图标的可点击链接呈现。
- 完成态提供“审核变更”和“撤销”；“审核变更”直接打开右侧工作台的审核功能。

`23–34` 是事件流的专项状态矩阵；其余工作台原型也复用同一套会话结构。

## HTML 完整 Demo

两份 HTML 使用同一个交互内核，状态与静态原型保持一一对应：

- 顶栏“原型场景”入口可直接切换 26 个状态；键盘 `[` / `]` 可切换上一个或下一个状态。
- 置顶、归档、审核、撤销、侧栏收起、子智能体列表与详情返回均可真实点击。
- 右侧工作台支持多标签、关闭当前页后回退到左侧相邻页、关闭最后一页后收起，以及空工作台重开后的默认功能选择。
- 快捷键可直接打开对应工具：`Ctrl+Alt+S` 上下文与子智能体、`Ctrl+\`` 终端、`Ctrl+P` 文件、`Ctrl+Shift+G` 审核。
- 输入框只保留一个模型配置入口；模型、Thinking、推理强度与输出详略在逐层浮层中按当前 Provider 能力显示。
- 多命令展开态包含 8 条命令并在清单内部滚动；它与页面主滚动互不干扰。
- 人工许可、失败重试、新任务示例和上下文文件选择均带可验证的状态变化。
- HTML Demo 中的当前命令使用从左到右的字符流光；静态 PNG 不启用该效果。
- 系统开启“减少动态效果”时，字符流光自动退化为静态灰色文字。
- 截图或评审时可在 URL 增加 `demoControls=0` 隐藏 Demo 场景入口。

更新两份 HTML：

```powershell
node docs/ui/prototypes/workbench/build-html-demos.cjs
```

## 覆盖审计

本轮反向审计补齐了五类主流程断点：任务尚未开始、工具等待人工许可、命令失败后的恢复、输入区引用上下文，以及右侧工作台标签的关闭与重开。至此，从“新建任务 → 运行与多次工具调用 → 人工许可 / 失败恢复 → 文件输出 → 审核 / 撤销 → 归档”的桌面主流程已经闭环。

仍可作为下一阶段补充、但不阻塞当前 Demo 的二级状态：首次登录与模型配置、离线 / 重连、合并冲突与部分接受 Diff、高对比度主题，以及小于 `1200px` 的极窄窗口策略。

## 右侧上下文与子智能体

右侧栏采用逐层展开，而不是同时堆叠所有信息：

1. 收起时保留一个轻量上下文面板，只显示环境信息、子智能体摘要和本轮来源文件。
2. 点击“子智能体”后展开右侧栏，按“进行中 · 数量 / 已完成 · 数量”分组显示；列表采用名称、单行摘要和右侧时间的扁平双行结构，运行项在身份角标上保留轻量动态反馈。
3. 点击任一子智能体进入详情，运行过程复用主交互区的连续阅读结构：流式片段合并为完整回答，连续工具归为可展开的一组，失败项不会被“已完成”状态掩盖。
4. 详情左上角的返回箭头回到子智能体列表；列表标题栏提供关闭标签、新增工具和收起工作台入口。
5. 子智能体默认只读；只有主智能体依据当前对话或明确的父任务要求以 `full_access` 委派时，详情才显示“完全访问”并开放写入与命令能力。

右侧工作台的标签生命周期与“隐藏面板”严格区分：

- 点击标签上的 `×` 会关闭该工具；若仍有其他标签，则激活它左侧相邻的标签。
- 点击工作区右上角的侧栏按钮只隐藏工作台，不关闭已有标签；再次点击会恢复原状态。
- 关闭最后一个标签会同时收起工作台；再次打开时进入默认功能选择器，不复活刚关闭的工具。
- 默认功能选择器提供审核、终端、浏览器、文件和侧边任务入口，并显示已注册快捷键。

`11/12 → 03/04 → 21/22` 对应这条交互链的三个关键状态。

## 桌面壳层与去重

- 顶栏提供侧栏切换、后退、前进，以及“文件 / 编辑 / 视图 / 帮助”菜单。
- 左侧边栏可以收起；`19/20` 专门展示收起后的紧凑布局。
- 桌面壳层采用两层结构：底层是一张连续的暖色背景，贯穿左侧栏与桌面顶栏；上层是由主交互区和右侧工作台共同组成的完整工作区。
- 上层工作区在“左侧栏右缘 × 桌面顶栏下缘”的交点使用 `20px` 左上大圆角，包住会话标题栏。圆角缺口露出的是底层同一张背景（包含连续光晕），不是另外填入的近似颜色。
- 圆角自身带一条可见轮廓，顶栏不再叠加第二条横线；主交互区与右侧工作台之间仍只使用内部单线分隔。
- `r-code` 只作为项目名保留在项目树中；会话标题下只显示“正在执行 / 已完成 / 正在审核”等状态。
- “替我审批”只保留在输入框的权限位置，不再重复显示作用域条。
- 侧栏与主区、会话与右侧工作台之间都只显示一条分隔线；拖动热区仍保留足够宽度。

## 表面层级

暗色主题以深黑主交互画布为底；左侧边栏、顶部/工具面板与输入框使用不同层级的浅黑。左栏叠加低强度暖色环境光，不作为功能强调色使用。

亮色主题使用同一套层级逻辑：暖灰侧栏、近白主画布、白色输入与卡片表面。

## R-Code Signature Dark

个性化暗色方案保留原有功能拓扑与工作区左上圆角，但使用一组 R-Code 自有视觉签名降低对单一参考产品的依赖：

- 侧栏改为炭灰底与铜橙局部环境光，选中态使用切入式定位线，不使用整块胶囊。
- 项目与任务状态从圆点改为细长刻度；代理头像改为非对称软方形。
- 主会话加入一条轻量“执行脊柱”，回答、命令、上下文压缩、子智能体与文件编辑保持时间顺序。
- 用户消息、输入框与详情面板采用不对称软方角，普通表面减少阴影。
- 右侧上下文简面板改为开放式信息架，仅用单线划分环境、子智能体与来源。
- 公开原型中的模型入口使用 `R-Code / Auto`，不把第三方产品名称作为界面品牌。

这套方案只改变视觉表达，不改变置顶、归档、审核、撤销、子智能体导航和事件展开语义。

## 重新渲染

原型从 [完整产品交互 Demo](../../demo/index.html) 读取结构和内容，但配色与会话操作通过原型渲染器注入，不修改正式前端实现。

在仓库根目录执行：

```powershell
node docs/ui/prototypes/workbench/render-workbench.cjs
```

渲染器会重建 `light/` 下的 20 张图片和 `dark/` 下的 24 张图片，并校验：

- 主画布、侧栏、输入框的颜色层级；
- 侧栏光晕存在；
- 桌面顶栏按钮和四个文字菜单完整可用；
- 主工作区圆角、侧栏收起与展开均正常；
- 项目名和权限文案没有重复；
- 面板之间只有一条可交互分隔线；
- 上下文简面板完整包含环境信息、子智能体与来源文件；
- 子智能体列表正确区分进行中与已完成状态；运行项显示实时耗时，完成项显示结束距今，身份角标具备轻量动画；
- 从简面板可以进入列表、从列表可以进入详情、详情返回箭头可以回到列表；
- 子智能体详情的 Session 摘要可以折叠并重新展开；
- Session 摘要、正文、命令和最终输出层级正确；
- 执行中只有一条当前命令，静态原型不会误带动效；
- 完成折叠只隐藏过程记录，最终回答保持可见；
- 多命令列表、单 Shell 输出和单文件 diff 只在各自展开态出现；多命令清单包含 8 条记录并具备内部滚动；
- 右侧工作台允许文件与审核多标签并存，关闭当前页会回到左侧相邻页；
- 关闭最后一页会收起工作台，重开后显示默认功能选择器而不复活已关闭标签；
- `Ctrl+Alt+S`、`Ctrl+\``、`Ctrl+P` 与 `Ctrl+Shift+G` 会打开对应工作台功能；
- “上下文已自动压缩”和子智能体状态各出现一次，且位于正确的时间顺序中；
- 文件输出使用带图标的编辑器链接；
- Session 摘要可以折叠并重新展开；
- “审核变更”可以跳转到右侧审核工作台；
- “撤销”可以直接切换为已撤销状态；
- 人工许可包含三种明确决策，并可从等待态进入执行态；
- 命令失败保留错误上下文，并提供重试与打开终端；
- 新任务示例可以回填输入区；
- 上下文选择器可以筛选文件并同步输入区引用标签；
- 默认状态操作隐藏；
- 悬停后恰好显示两个操作；
- 置顶直接生效；
- 归档无确认框；
- 紧凑窗口无页面溢出。

只重新生成个性化暗色方案时执行：

```powershell

```

该模式只发布到 `dark/r-code-signature/`，不会覆盖 `dark/` 顶层的原始暗色图片；24 张全部通过验证后才会一次性替换目标目录，并保留其中的 `demo.html`。失败时自动清理本轮临时输出。
