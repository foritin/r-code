# Product facts — Codex workbench reference

更新时间：2026-07-28

- OpenAI 于 2026-02-02 发布 Codex 桌面应用，并在 2026-03-04 的更新说明中确认 Windows 版本可用。
- OpenAI 将 Codex App 定义为多智能体的 command center：任务按项目组织，可并行运行，并可在任务中审核变更、评论 diff、打开编辑器继续手工修改。
- Codex App 的核心产品模式不是“固定信息侧栏”，而是对话旁边可打开的工作区：终端、文件、审核和并行任务按需占用更宽的画布。
- 本轮视觉事实主要来自用户在 2026-07-28 提供的四张 Codex App 实际截图；OpenAI 官方发布页只用于确认产品定位与能力边界，不用于逐像素复制。
- R-Code 原型只迁移“对话保持稳定 + 右侧按需打开工作台 + 标签页承载工具”的信息架构，不使用 Codex 名称、Logo、专有图形或品牌配色。

官方来源：<https://openai.com/index/introducing-the-codex-app/>
