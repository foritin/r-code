# 远程控制（Remote Control）

用手机（或任何浏览器）查看和操作你电脑上的 R-Code 会话。连接是**点对点**的：
手机直接连到你电脑上运行的 R-Code 后台服务，没有任何中间服务器、账号或订阅。

## 工作原理（30 秒版）

1. 电脑端开启配对，生成一个**一次性配对码**（120 秒内有效）。
2. 手机浏览器打开 R-Code 控制台，输入配对码完成配对。
3. 配对产生一个**设备令牌**，只保存在你的手机上；电脑只保存它的哈希。
4. 此后手机通过加密通道（TLS + 证书指纹钉扎）连接电脑，看到任务列表、
   实时事件流，并按授权能力发送消息或审批工具调用。

默认状态下 R-Code **不监听任何网络端口**：没有配对过设备、或吊销了全部设备，
网络面即关闭（端口扫描不可见）。

## 配对

### 电脑端

- 桌面应用 / TUI：进入远程控制设置，选择「开始配对」（TUI `/remote`）。
- 命令行：向 daemon 发送 `remote.pairingStart`（仅本机连接可调用）。

配对码展示 120 秒，只能使用一次；再次开始配对会使旧码作废。

### 手机端

打开控制台（局域网内 `https://<电脑IP>:<端口>/app/`），输入：

- 主机地址（电脑的局域网 IP）
- 端口（配对时展示）
- 设备 ID 与设备令牌（配对成功后返回，自动保存）

扫码配对（QR 载荷 `rcode://pair?v=1&...`）与手动输入完全等效。

## 能力（权限）

每台设备在配对后获得能力集合，能力由**电脑端强制**（手机端绕过无效）：

| 能力 | 允许的操作 | 默认 |
| --- | --- | --- |
| `events-read` | 查看任务列表、事件流、待审批 | ✅ 始终 |
| `tasks-write` | 发送消息、取消、重命名、克隆任务 | ❌ |
| `approvals-decide` | 批准/拒绝工具调用 | ❌ |

设置类（provider/凭据）、插件安装、设备管理、服务关闭等**任何能力组合都
不可远程调用**（服务端硬编码拒绝）。

高敏任务可开启 `require_desktop_confirm`：远程设备只能看到
`needs_desktop_confirm`，最终批准必须由电脑本机完成。

## 吊销与管理

电脑端设备管理（桌面设置 / TUI `/remote`）：

- **吊销**：立即断开该设备的活动连接，拒绝重连（提示 `revoked`）。
- **调整能力**：收窄立即生效（连接会被断开以重新认证）。
- **监听开关**：关闭后断开所有远程连接但保留设备记录；重新开启即可恢复。

设备令牌只在配对响应中出现一次；手机端清除浏览器数据即等于本机注销
（电脑端的吊销仍然生效）。

## 安全模型

- **传输加密**：自签名证书 + TLS；手机只信任配对时钉扎的证书指纹
  （SHA-256，进入配对码/QR）。指纹不符 = 硬错误，没有"继续访问"。
- **令牌存储**：设备令牌 32 字节随机；电脑端只存 SHA-256（registry.json，
  用户私有目录 0600 语义）。
- **配对码**：≥128 位熵、一次性、120 秒、不落盘（daemon 重启即失效）。
- **审批审计**：每次决策的 `decidedBy`（设备 id 或 `<timeout>`）写入任务
  journal。无人决策 300 秒后自动拒绝。
- **无账号**：没有云端组件；手机与电脑之间是仅属于你的直连。

## 端口与防火墙

远程监听端口在**开始配对时**动态分配（只绑定私网地址，绝不 `0.0.0.0`）。

- **Windows**：首次监听时系统会弹出防火墙授权提示，选择「允许（专用网络）」。
  拒绝后远程连接不通；可在「Windows Defender 防火墙 → 允许应用」中为
  `r-code-service` 重新放行（仅专用网络）。
- **macOS**：系统不弹提示。若开启「阻止所有传入连接」或在隐身模式，需在
  「系统设置 → 网络 → 防火墙」为 `r-code-service` 添加允许规则。
- **Linux**：无系统弹窗。`ufw` 用户：`ufw allow in on <网卡> to any port <端口> proto tcp`；
  `firewalld` 用户：`firewall-cmd --add-port=<端口>/tcp`。端口是动态的，
  也可以在设备管理中固定（`device.setListener`）。

局域网之外（外网/蜂窝网络）访问需要自托管中继（见下）。

## 与中继的关系

跨网络访问时可选部署**自托管中继**（`r-code-relay`）：中继只转发加密字节，
无法解密内容，也没有账号体系。默认不配置中继——不配置就没有任何出站/入站
中继连接。详见中继部署手册（R20 交付物）。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 连接不上电脑 | 确认电脑在线且同一网络；防火墙放行（见上节）；端口与配对展示一致 |
| 「主机身份校验失败」 | 电脑证书变化（重装/重置）。在电脑端重新配对，手机端清除旧凭据 |
| 「认证失败」 | 配对码已过期或设备被吊销。重新配对 |
| 看得到任务但发送按钮灰色 | 该设备未授予 `tasks-write`；在电脑端设备管理中调整 |
| 收不到审批提醒 | 浏览器通知权限被拒——在浏览器设置中允许，或使用应用内横幅 |
