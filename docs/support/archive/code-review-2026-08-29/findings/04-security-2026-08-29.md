### 总体结论

本仓库安全工程质量显著高于同类桌面 AI 代理应用的平均水平：

- **路径边界**：核心是 `PathGuard`（crates/r-code-core/src/security.rs:71-934），基于 cap-std 目录 capability，fail-closed，覆盖 `..` 穿越、符号链接替换竞态（TOCTOU）、Windows junction/reparse、cwd 逃逸、`\\?\` verbatim 前缀差异；`file_read/file_write/file_list` 全部经 `attached_workspace_root`（workspace 必须已在 DB 注册）+ PathGuard。zip/tar 解压（rtk.rs）只读 entry 字节、不落盘成员路径，无 zip-slip 面，且下载带 sha256 pin + 版本探针 + 失败回滚。
- **命令执行**：所有 `cmd.exe /C` 用点均为「固定字面量参数 + 路径经 `windows_cmd_safe_path` 元字符拒绝」模式，WebView 文本不进命令行；MCP stdio 在 Windows 拒绝 .bat/.cmd/.ps1/cmd/powershell/wscript/npx 启动器（防 BatBadBut）；macOS 临时登录脚本用标准 posix 单引号转义。
- **凭据**：API key 只进平台凭据库（Win/Linux keyring，macOS 0600/0700 AEAD 文件 + Zeroizing），TOML 永远剥离；`settings_get` 返回前清空；`settings_set` 拦截 `providers.*.api_key` 直写 keyring；日志三层脱敏（字段名白名单 + 消息正则 + 落盘前/回读时双保险）；support bundle 只收白名单 DTO。
- **SQL**：动态拼接仅限编译期常量列名/本地白名单表名，全部参数化。
- **XSS**：零 dangerouslySetInnerHTML；自研 Markdown parser 在解析期做 scheme 白名单（含控制字符混淆对抗）。
- **IPC/Tauri**：CSP 收敛（script-src 'self'，无 unsafe-eval）；capabilities 最小化（无 fs/shell 插件权限，仅 opener:default + updater:default）；navigation guard 已实际挂载（main.rs:326）；updater 带 minisign pubkey。
- **SSRF**：模型侧 web fetch（web.rs）有 scheme/内网 IP/DNS-pinning/重定向逐跳重校验/跨域剥离凭据的完整防护；余额查询硬编码 api.deepseek.com 主机白名单。

未发现 blocking 级问题。以下为 minor/加固级 findings。

## 逐条展开

### F-sec-01 控制台日志层绕过脱敏（minor）

- 证据：`logging.rs:74-77`（生产）与 `100-103`（开发）的 subscriber 均为 `registry().with(env_filter).with(console_layer).with(BufferLayer::new(writer))`。脱敏（`redact_text` + `sensitive_log_field` 字段名白名单，log_buffer.rs:89、270-299）只实现于 `BufferLayer`；`console_layer`（`fmt::layer()`）直接格式化原始事件字段。
- 根因：脱敏被实现为「一个 Layer 的行为」而非 subscriber 前置 filter，控制台通道被遗漏。
- 利用条件：用户从终端启动应用（或 stderr 被父进程/崩溃收集器捕获），且某处 tracing 事件的 message/字段恰好携带密钥形态文本。当前代码纪律良好（settings.rs:656 注释「不会将值记录到日志」、网络错误经 `sanitize_network_error`），实际触发面小，故定级 minor。
- 备注：`log_buffer.rs:196-198` 对历史磁盘日志回读时二次脱敏、`support_bundle.rs:169` 导出时再次脱敏，纵深充分——唯独 console 通道无防护。

### F-sec-02 `cmd_reveal_local_path` 无路径白名单（minor）

- 证据：`tauri_commands.rs:1941-1943`：`pub async fn cmd_reveal_local_path(path: String) -> Result<(), String> { r_code_host::system_integration::reveal_in_file_manager(Path::new(&path)) }`。`system_integration.rs:65-71` 仅检查存在性；Windows 走 `explorer.exe [/select,] <path>`（参数独立传递，无注入）。
- 根因：与 `file_read`（必须 attached workspace + PathGuard）不同，此 command 是「在文件管理器中显示」的快捷通道，设计上服务于 External 产物（Codex 生成物），但没有像 `local_image_preview` 那样把 External 收敛到 `codex_home/generated_images`（commands.rs:14396-14418 有先例）。
- 利用条件：仅当 WebView 被攻破（XSS/供应链）时，攻击者可用它打开任意目录/选中任意文件（存在性 oracle + UI 骚扰）；无命令执行、无内容读取。与 opener:default 能力等价，故 minor。

### F-sec-03 工作区 provider 覆盖 + keyring 注入的潜伏外泄链（minor，当前不可达）

- 证据链：
  1. `settings.rs:577-621` `load_with_workspace`：全局 config 被 `{workspace}/.r-code/config.toml` 深度合并（`merge_toml`）；
  2. `settings.rs:779-788` `hydrate_secrets`：对合并结果中每个 api_key 为空的 provider，按 provider **名**（`secret_key = "provider:{name}"`，settings.rs:774-777）从平台凭据库取值回填；
  3. 若恶意仓库携带 `[providers.anthropic] base_url="https://attacker.example"`，合并后名为 anthropic 的 provider 将拿到用户真实 key 并指向攻击者。
- 现状核查：`rtk proxy grep -rn "load_with_workspace" src-tauri/src crates` 仅命中 settings.rs 定义处与测试（settings.rs:1491/1513/1563）；生产运行时 provider 解析走 `load_global_unvalidated`（commands.rs:2057/3583/5085 等），prompt overlay 走独立的 `resolve_agent_prompts`（读取的是 appdata 下 blake3 digest 目录，settings.rs:401-411，非工作区文件）。**链路当前未接线**。
- 根因：API 把「不可信输入（仓库内容）」与「凭据注入」放进同一个函数而没有任何来源标记。
- 修复方向（接线前必须）：对来自工作区 override 的 provider 条目默认不注入 keyring 凭据；或仅当 override 后 base_url/provider_kind 与用户全局配置逐字节一致时才注入。

### F-sec-04 `resolve_local_file_target` 任意路径 metadata oracle（minor）

- 证据：`commands.rs:14312-14357`：reference（来自聊天 Markdown 链接，模型可影响）→ `local_path_from_reference` 接受绝对路径与 `file:` URL → `candidate.canonicalize()` + `std::fs::metadata`，对 workspace 外路径返回 `absolute_path/size_bytes/mime_type/is_directory`（scope=External）。
- 缓解：文件**内容**不泄露——External 预览被硬限制在 `codex_home/generated_images`（commands.rs:14396-14418），编辑器读写全部 PathGuard。
- 根因：「显示外部产物路径」的产品需求使探测逻辑无边界；错误信息（"cannot resolve local file ..."）同时构成存在性 oracle。
- 利用条件：模型诱导用户点击链接或前端自动解析引用；收益仅为确认某文件是否存在/多大。minor。

### F-sec-05 CSP `style-src 'unsafe-inline'`（信息级）

- 证据：`tauri.conf.json:32`。`security_config.rs:132-137` 有测试保证生产 CSP 无 `unsafe-eval`、无 `ws://`；script-src 为 `'self'`。React 生态内联样式普遍需要该项，实际可利用面（CSS 注入）极低。维持现状可接受。

### F-sec-06 终端 shell 参数无白名单（威胁模型内，minor）

- 证据：`tauri_commands.rs:1221-1227` `shell: String` → `commands.rs` → `manager.rs:638-647` `resolve_shell`（非 "auto" 时原样返回）→ `manager.rs:208` `CommandBuilder::new(&shell)`（参数数组传递，无 shell 拼接）。
- 语境：本产品命令执行本身是功能（agent 工具网关 + 权限引擎 R0-R4 审批）；WebView 妥协前提下此 command 不增加新权限面。列出仅为完整性。

### F-sec-07 开发环境 CSP 放宽（仅开发期）

- 证据：`security_config.rs:47`（dev CSP 含 `unsafe-eval`、`ws://localhost:*`）；`tauri.conf.json:33` `devCsp: null`（开发构建不注入 CSP）。生产配置（tauri.conf.json:32）不受影响；`main.rs:326-333` navigation guard 实际阻断 javascript:/file:/vbscript:/data: 导航。

### F-sec-08 NSIS 进度桥任意路径写入固定内容（低影响）

- 证据：`installer-hooks.nsh:5-13`：`GetOptions $CMDLINE "/BRANDED_PROGRESS=" $R8` 后 `FileOpen $R9 "$R8" w` 写固定字符串。安装器以用户主动运行 + 签名为前提，攻击者需控制安装命令行参数，收益仅为用固定内容截断任意文件。修复：限制 `$R8` 必须位于 `$TEMP` 下。
- 附带核查：`uninstall-cleanup.ps1` 的 `$BundleId` 有 `ValidatePattern` 白名单，且有 managed 目录 ownership 检查，无注入面。

## 已核查为安全的重点面（供后续 review 复用）

1. **PathGuard**（crates/r-code-core/src/security.rs）：cap-std capability 相对打开、canonicalize 后 containment 校验、`normalized_workspace_path` 词法拒绝 `..`/根/前缀组件、junction/symlink fail-closed、原子写不创建父目录；配套 30+ 安全测试（含 Windows junction 四入口全覆盖测试 security.rs:1172-1235）。
2. **RTK 安装链**（rtk.rs:298-383）：常量 URL + 固定 tag + 每 asset sha256 pin（313-317 强制）→ 有界下载 → 内存解压（无路径解压）→ staging 原子激活 → 版本探针 → 失败回滚。
3. **MCP 启动**（crates/r-code-mcp/src/client.rs:252-311）：`reject_unsafe_windows_launcher` 拒绝 bat/cmd/ps1/cmd/powershell/wscript/cscript/npx/npm；args 数组传递；env 经 SecretRef 间接解析；HTTP transport header 值经 HeaderValue 校验。mcp_manager 有「新启动形态默认 disabled + 确认 token」双步流（mcp_manager.rs:948-991）。
4. **codex_permissions.rs**：枚举闭式映射，未知字符串降级 read-only + Never（from_config），`config_override()` 只产生固定 TOML 片段；R-Code 写 Codex config.toml 用 toml_edit 结构化编辑（commands.rs:17660-17702），无字符串拼接注入。
5. **web.rs SSRF**（crates/r-code-mcp/src/web.rs:390-505）：scheme 白名单、拒绝内嵌凭据、拒绝 localhost/.local、DNS 解析结果 IP 黑名单（私网/环回/CGNAT/组播/保留段，638-660）、`approved_addresses` 传给 HTTP 层（防 DNS rebinding）、每跳重定向重新校验、跨域重定向剥离 authorization/cookie/x-subscription-token、Jina fallback 不转发任何凭据。
6. **凭据链**：SecretStore 写后回读验证（secret.rs:103-119）；macOS AEAD（ChaCha20-Poly1305 + 0600/0700 + Zeroizing + 文件锁）；旧 TOML 明文自动迁移（settings.rs:715-734）；`internal_secret` 保留命名空间防 provider 名碰撞（settings.rs:680-709）；MCP 凭据 account 组件拒绝 `/ \ :` 与控制字符（security_config.rs:96-107）。
7. **日志/支持包**：BufferLayer 字段级脱敏（token/apikey/password/clientsecret/aws_* 等 17+ 字段名）+ `redact_text` 正则（私钥块、URL 凭据、Bearer、sk-/ghp_/github_pat 等）+ 回读重脱敏 + 7 天保留期；support bundle 只含白名单 DTO（MCP 摘要无命令/参数/URL/头）。
8. **SQL**：`repositories.rs:699`、`plan_review.rs:1995`、`support_bundle.rs:234`、`migration.rs:624/686` 的 format! 片段均为常量列名/本地表名白名单；其余全部参数化。
9. **前端**：0 处 dangerouslySetInnerHTML/innerHTML/eval；Markdown 解析期 scheme 白名单 `^(https?|mailto|file):` + 控制字符剥离（markdown.ts:546-572），被拒 scheme 降级为纯文本；远程图片不加载（渲染为惰性链接）；外链统一 `rel="noopener noreferrer"`；apiKey 只存 React state，经 invoke 提交，不落 localStorage。
