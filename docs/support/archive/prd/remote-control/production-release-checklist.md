# 真机外网验收清单（R28，production_release_ready）

> 本清单无法在 CI/loopback 取证；由用户在真机 + 真实网络环境执行。
> 通过任意一项请在清单后追加日期与环境记录。

## 前置

- [ ] iOS TestFlight 包（开发者账号签名）或 Android debug/release APK 安装到真机。
- [ ] 一台运行 R-Code 桌面版（R07+ 构建）的电脑，位于另一网络（家里/办公室）。
- [ ] 一台公网 VPS 已部署 r-code-relay（见 relay-deployment.md），域名+TLS。
- [ ] 手机处于 4G/5G 或外网 Wi-Fi（与电脑不在同一网段）。

## 1. 真机组网与远程监听

- [ ] 电脑端生成配对码（relay 已配置，owner 注册码已导入中继）。
- [ ] 手机 App 扫码（或手动输入）完成配对；证书指纹逐段核对一致。
- [ ] 手机在外网经中继看到电脑端任务列表（不依赖局域网）。
- [ ] 抓包确认：中继域名外无其他连接；中继流量为加密二进制帧。

## 2. 真实蜂窝往返

- [ ] 手机发送一条消息，电脑端 run 完成后事件流回传（双向 ≤ 30s 级，视网络）。
- [ ] 弱网（电梯/地铁）断连：App 显示「连接断开，N s 后重试」，恢复后自动重连，after_seq 续传不丢事件。

## 3. 真机审批

- [ ] 电脑端发起需审批的工具调用；手机收到前台通知（正文为通用文案，无命令内容）。
- [ ] 手机批准 → 电脑端插件继续执行；手机拒绝 → 插件收到 Denied 后 run 终态。
- [ ] require_desktop_confirm 任务：手机收到「需要在电脑上确认」引导，无法终决。

## 4. 吊销

- [ ] 电脑端吊销手机设备：手机当前连接立即断开（watch 通道）。
- [ ] 手机杀进程后重开：重连被拒（revoked），引导重新配对。
- [ ] 即使中继仍接受该设备连接（纵深防御验证），daemon 侧仍拒绝命令。

## 5. 高敏终桌面确认

- [ ] 开启 require_desktop_confirm 的任务，手机与桌面行为符合 R12 契约。
