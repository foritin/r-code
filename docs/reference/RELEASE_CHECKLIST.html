M12 Release Checklist

Unsigned public Beta (1.0.0-beta.3)

  • SemVer prerelease version and matching v1.0.0-beta.3 tag policy.
  • Unsigned releases are restricted to prerelease channels; unsigned Stable fails closed.
  • macOS, Windows and Linux native package/install workflows are defined.
  • E2E-023 migration and backup restore coverage.
  • E2E-024 real packaged-application coverage.
  • Static, unit, performance, Electron E2E, security, soak and dependency gates are wired into release:verify.
  • DMG clean install/launch/cleanup smoke passed locally.
  • SPDX SBOM, license inventory, third-party notices, artifact manifest and SHA-256 checksums are generated.
  • Security, privacy, recovery, signing, known-limitations and release-note documents are present.
  • GitHub tag workflow creates a Prerelease only after all native package jobs pass.
  • The tag workflow blocks publication until its release gates and macOS, Windows and Linux package matrix pass.
  • The publish job creates a GitHub Prerelease with --latest=false and attaches native packages, manifest, checksums and SBOM.

Beta 2 was the first downloadable preview. Its 13 assets and corrected Prerelease metadata remain
available at v1.0.0-beta.2.

Stable handoff (intentionally not claimed)

  • Obtain Apple Developer Program membership and Developer ID Application credentials.
  • Configure Apple notarization credentials and validate Gatekeeper acceptance.
  • Obtain a trusted Windows code-signing certificate and validate SmartScreen/install behavior.
  • Run Beta-to-Stable update/rollback coverage for the chosen updater service.
  • Run the fixed 20-task real-provider evaluation with owner-approved credentials.
  • Obtain product-owner sign-off on the Stable test report.

The user selected the zero-cost Beta path. These Stable items do not block the GitHub Prerelease, but they do block any build labeled Stable.
