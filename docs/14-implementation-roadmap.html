1. 概述

本文档定义 Rust 重构的分阶段实施计划，确保每一步都产生可验证的交付物，
并保持应用可运行。

2. 阶段划分

阶段 0：原型验证（2-4 周）

目标：验证 Tauri + Rust 技术栈可行性

任务交付验收
Tauri 骨架搭建窗口、菜单、多窗口应用可启动
IPC 通道实现JSON-RPC 2.0 通信请求/响应/事件正常
React 渲染层迁移基础 UI 在 WebView 运行页面可渲染
SQLite 集成rusqlite 基础 CRUD数据可读写

阶段 1：基础设施（4-6 周）

目标：完成核心基础设施迁移

任务交付验收
持久化层完整 schema + migration所有表创建成功
配置管理SettingsService配置可读写
日志系统结构化日志日志可输出
错误处理统一错误类型错误可追踪

阶段 2：核心服务（6-8 周）

目标：完成 Tool Gateway 和 Permission Engine

任务交付验收
Tool Gateway工具注册 + 执行工具可调用
Permission Engine风险分级 + 审批权限可控制
Command Classifier动态分类分类准确
Ledger全量记账记录完整

阶段 3：终端系统（4-6 周）

目标：完成终端相关功能

任务交付验收
PTY 管理portable-pty 集成终端可创建
Shell 集成OSC 133 注入命令可追踪
块模型解析command/turn 解析块可识别
外部 CLI 检测进程轮询检测准确

阶段 4：Agent 集成（4-6 周）

目标：完成 Agent 运行时集成

任务交付验收
Agent Worker独立进程进程可管理
IPC 通信Worker ↔ Main通信正常
事件流AgentEvent 映射事件可投影
任务状态机完整状态转换状态正确

阶段 5：渲染层迁移（4-6 周）

目标：完成 UI 层迁移

任务交付验收
Home 表面启动器 + Mission Control功能完整
Task Room时间线 + 审批 + 审查功能完整
Editor文件树 + 编辑器 + 终端功能完整
设置所有设置页功能完整

阶段 6：外部 CLI 编排（3-4 周）

目标：完成会话编排功能

任务交付验收
terminal.* 工具六个原语工具可用
外部控制门Unix Socket HTTP门可访问
指令面投影Skill + AGENTS.md投影正确
审批模型单记录多入口审批可用

阶段 7：测试与验证（4-6 周）

目标：完整测试覆盖

任务交付验收
单元测试核心模块覆盖覆盖率 ≥ 80%
集成测试服务间集成流程可走通
E2E 测试Playwright 适配关键路径通过
性能基准对比测试性能不降级

阶段 8：发布准备（2-4 周）

目标：准备发布

任务交付验收
打包配置tauri.conf.json可打包

6. 验收标准

每个阶段结束时：

  • 所有交付物已完成
  • 相关测试已通过
  • 文档已更新
  • 应用保持可运行
  • 性能基准未退化
