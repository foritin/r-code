UI/UX 设计系统

1. 概述

Charter 的 UI/UX 设计遵循 Studio 视觉语言，暖纸浅色主题 + 匹配深色主题，
衬线显示字体用于 Home 标题，12-14px 圆角卡片，柔和阴影。
两个表面共享相同的设计 tokens。

7. 交互模式

7.1 拖拽

  • 文件/文件夹 → 路径引用 chips
  • @ 打开文件选择器
  • 项目外条目跳过并 toast 说明

7.2 键盘导航

  • ⌘E: 切换到 Editor
  • ⌘K: 全局搜索
  • Tab 顺序遵循视觉顺序

7.3 快捷键

快捷键操作
⌘E切换 Editor
⌘K快速打开
⌘⇧P命令面板
⌘W关闭标签
⌘,设置

8. 响应式设计

8.1 断点

  • 桌面: ≥1280px
  • 平板: 768-1279px
  • 移动端: <768px (未来)

8.2 窗口缩放

  • Session Canvas 断点改容器查询
  • 窄窗错位修复
