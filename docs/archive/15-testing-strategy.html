3. 单元测试

3.1 Rust 单元测试

  • 每个 crate 内含 #[cfg(test)] mod tests。
  • 使用 cargo test 运行。
  • 覆盖率目标：≥ 80%。
rust
#[cfg(test)]
mod tests {
    use super::*;
    
    #[test]
    fn test_path_guard_canonical() {
        let guard = PathGuard::new("/workspace");
        let result = guard.resolve("/workspace/file.txt");
        assert!(result.is_ok());
    }
    
    #[test]
    fn test_path_guard_escape() {
        let guard = PathGuard::new("/workspace");
        let result = guard.resolve("/etc/passwd");
        assert!(result.is_err());
    }
}

7. 安全测试

7.1 秘密扫描

  • 扫描代码中的 API key、令牌。
  • CI 集成。

7.2 依赖审计

  • cargo audit 检查已知漏洞。
  • 无 Critical/High 漏洞。

7.3 边界测试

  • 路径穿越
  • 符号链接逃逸
  • TOCTOU 竞争
  • 缓冲区溢出

8. 测试命令

bash
# 运行所有测试
cargo test

# 运行特定模块测试
cargo test path_guard

# 运行集成测试
cargo test --test integration

# 运行 E2E 测试
npx playwright test

# 运行性能测试
cargo bench

# 运行安全扫描
cargo audit

9. CI/CD 集成

9.1 CI 流程

text
代码提交 → 格式检查 → 编译 → 单元测试 → 集成测试 → E2E 测试 → 安全扫描

9.2 质量门禁

  • 格式检查：cargo fmt --check
  • Lint：cargo clippy
  • 测试通过率：100%
  • 覆盖率：≥ 80%
  • 安全扫描：无 Critical/High
