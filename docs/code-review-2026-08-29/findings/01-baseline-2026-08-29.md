# RV-01 基线结构 findings（2026-08-29）

## 仓库结构

- Rust workspace（resolver=2, edition 2021, rust 1.88），成员：
  - vendor 公共合同（submodule `vendor/agent-contracts`，pinned）：agent-error / agent-contract / agent-llm / agent-mcp / agent-store / agent-config / agent-compaction / agent-ipc / agent-tauri
  - 产品私有：`crates/r-code-core` `r-code-store` `r-code-gateway` `r-code-mcp` `r-code-terminal` `r-code-agent-worker` + `installer` + `src-tauri`（package 名 r-code-host）
- 前端：`src-tauri/frontend/`（React + TS），入口 `src/main.tsx` -> `App.tsx`
- 桌面入口：`src-tauri/src/main.rs`（50KB）+ `lib.rs`
- 另有 submodule `.agents`（kimi.git，skills 仓库，只读）

## 依赖图（内部边，已验证无循环）

```
agent-* (vendor, 无内部产品依赖)
r-code-core        -> agent-contract/error/llm/store/config/compaction/mcp
r-code-store       -> r-code-core + agent-contract/error
r-code-gateway     -> r-code-core + agent-contract/error
r-code-mcp         -> agent-contract/error
r-code-terminal    -> r-code-core + r-code-gateway
r-code-agent-worker-> r-code-core/gateway/mcp + agent-llm/config/store
r-code-host(src-tauri) -> 以上全部 + agent-ipc/tauri/store/llm
installer          -> （无内部依赖）
```

分层：vendor 合同 <- core <- {store, gateway, mcp, terminal} <- agent-worker <- host。crate 级无循环依赖，拓扑干净。
