Workspace 与文档服务

1. Workspace 服务

1.1 概述

Workspace 服务管理项目打开/关闭、最近项目、信任模型。
Workspace 是 Agent 工具执行的根目录边界。

1.2 当前实现

  • WorkspaceHost + workspaces 表 + trust prompt。
  • canonical path、文件树、忽略规则、监听器。

1.3 信任模型

信任状态说明
untrusted未信任，工具只能读
trusted已信任，工具可读写

1.4 文件监听

  • 递归 watcher。
  • 过滤 .git/、ignore globs、产品 artifacts。

1.5 Rust 实现要点

rust
use notify::{Watcher, RecursiveMode, watcher};
use std::sync::mpsc::channel;

struct WorkspaceHost {
    workspaces: HashMap<WorkspaceId, WorkspaceHandle>,
    watcher: RecommendedWatcher,
}

struct WorkspaceHandle {
    id: WorkspaceId,
    path: PathBuf,
    trust_state: TrustState,
    file_tree: FileTree,
}

impl WorkspaceHost {
    fn open(&mut self, path: &Path) -> Result<WorkspaceId, WorkspaceError> {
        let canonical = path.canonicalize()?;
        let id = WorkspaceId::new();
        let handle = WorkspaceHandle {
            id: id.clone(),
            path: canonical,
            trust_state: TrustState::Untrusted,
            file_tree: FileTree::new(),
        };
        self.workspaces.insert(id.clone(), handle);
        self.watch(&id)?;
        Ok(id)
    }
    
    fn set_trust(&mut self, id: &WorkspaceId, trusted: bool) -> Result<(), WorkspaceError> {
        let handle = self.workspaces.get_mut(id)?;
        handle.trust_state = if trusted { TrustState::Trusted } else { TrustState::Untrusted };
        Ok(())
    }
    
    fn watch(&mut self, id: &WorkspaceId) -> Result<(), WorkspaceError> {
        let path = self.workspaces.get(id)?.path.clone();
        let tx = self.watcher_tx.clone();
        self.watcher.watch(&path, RecursiveMode::Recursive)?;
        // 处理事件
    }
}

2. Document 服务

2.1 概述

Document 服务管理编辑器文档的 revision/hash/dirty 模型，
支持二进制文件、大文件、EOL 处理。

2.2 核心概念

  • DocumentStore：文档存储。
  • Revision：文档版本。
  • Dirty：脏标记（未保存）。
  • Conflict：外部变更冲突。

2.3 文档模型

sql
CREATE TABLE documents (
    id TEXT PRIMARY KEY,
    workspace_id TEXT NOT NULL REFERENCES workspaces(id),
    path TEXT NOT NULL,
    content_hash TEXT,
    encoding TEXT NOT NULL DEFAULT 'utf8',
    eol TEXT NOT NULL DEFAULT 'lf',
    is_binary INTEGER DEFAULT 0,
    is_dirty INTEGER DEFAULT 0,
    last_modified INTEGER,
    saved_at INTEGER,
    UNIQUE(workspace_id, path)
);

2.4 大文件处理

  • 可编辑上限（超过则只读）。
  • BOM 处理。
  • 编码检测。

2.5 外部变更处理

  • Reload（重新加载）
  • Compare（比较）
  • Keep（保留当前）

2.6 Rust 实现要点

rust
struct DocumentStore {
    db: Arc<Database>,
    documents: HashMap<DocumentId, Document>,
    dirty_docs: HashSet<DocumentId>,
}

struct Document {
    id: DocumentId,
    workspace_id: WorkspaceId,
    path: PathBuf,
    content: String,
    hash: String,
    encoding: Encoding,
    eol: Eol,
    is_binary: bool,
    is_dirty: bool,
    revision: u64,
}

impl DocumentStore {
    fn open(&mut self, workspace_id: &WorkspaceId, path: &Path) -> Result<DocumentId, DocError> {
        let content = std::fs::read_to_string(path)?;
        let hash = blake3::hash(content.as_bytes()).to_hex().to_string();
        let doc = Document {
            id: DocumentId::new(),
            workspace_id: workspace_id.clone(),
            path: path.to_path_buf(),
            content,
            hash,
            encoding: Encoding::UTF8,
            eol: Eol::LF,
            is_binary: false,
            is_dirty: false,
            revision: 0,
        };
        let id = doc.id.clone();
        self.documents.insert(id.clone(), doc);
        Ok(id)
    }
    
    fn save(&mut self, id: &DocumentId) -> Result<(), DocError> {
        let doc = self.documents.get_mut(id)?;
        std::fs::write(&doc.path, &doc.content)?;
        doc.is_dirty = false;
        doc.hash = blake3::hash(doc.content.as_bytes()).to_hex().to_string();
        doc.revision += 1;
        Ok(())
    }
    
    fn detect_conflict(&self, id: &DocumentId) -> bool {
        // 检测外部变更
    }
}

3. Verification 服务

3.1 概述

验证服务管理验证命令、测试结果、完成报告和"未验证"警示。

3.2 验证流程

  1. Agent 完成任务。
  2. 执行验证命令。
  3. 根据 exit code 判断：
  • 0 → verified
  • 非 0 → failed
  • 未执行 → unverified

3.3 验证状态

状态说明
verified验证通过
failed验证失败
unverified未验证
skipped用户跳过

3.4 Rust 实现要点

rust
struct VerificationService {
    db: Arc<Database>,
}

struct VerificationCommand {
    task_id: String,
    command: String,
    exit_code: Option<i32>,
    output: Option<String>,
    status: VerificationStatus,
}

enum VerificationStatus {
    Pending,
    Running,
    Verified,
    Failed,
    Unverified,
    Skipped,
}

impl VerificationService {
    fn execute(&self, task_id: &str, command: &str) -> Result<VerificationStatus, VerifyError> {
        let output = Command::new("sh")
            .arg("-c")
            .arg(command)
            .output()?;
        
        let status = if output.status.success() {
            VerificationStatus::Verified
        } else {
            VerificationStatus::Failed
        };
        
        // 记录结果
        self.record_result(task_id, command, &output)?;
        
        Ok(status)
    }
}

4. Skills 系统

4.1 概述

Skills 是可复用的技能文件夹，模型按 description 自动调用，
或用户显式 /skill:name 唤起。

4.2 信任模型

  • Off：完全不生效。
  • Auto：启用，导入默认。
  • Manual：仅 /skill:name 显式可用。

4.3 加载机制

  • load_skill 网关工具（R0）。
  • 从托管库读 SKILL.md 或打包引用文件。
  • 路径穿越拒绝。
  • 每次加载进 tool audit。

4.4 安全约束

  • 绝不扫描项目目录。
  • 脚本零特权。
  • 加载可审计。
