渲染层

1. 概述

渲染层使用 React + TypeScript 构建，运行在 Tauri WebView 中。
包含 Monaco Editor、xterm.js 终端、以及所有 UI 组件。

2. 技术栈

2.1 当前实现

  • Electron Renderer（Chromium）。
  • React 18 + TypeScript。
  • Monaco Editor。
  • xterm.js。

2.2 Rust 迁移

  • Tauri WebView（系统 WebView）。
  • React 代码大部分可复用。
  • Monaco 和 xterm.js 在 WebView 中运行。

3. 信息架构

3.1 三层结构

text
Home (启动器 + 任务控制台)
  └─ Task Room (每任务页)
       └─ Editor (按需完整 IDE)

3.2 Home

  • 项目选择器。
  • 模型选择器。
  • 审批选择器。
  • 最近任务列表。
  • Mission Control。

3.3 Task Room

  • 对话时间线。
  • 计划/权限/问题卡片。
  • 变更 + 验证轨道。
  • 决策面板。
  • 回复 composer。

3.4 Editor

  • 文件树。
  • 编辑器标签。
  • 终端面板。
  • Git 面板。
  • 搜索面板。

4. 状态管理

4.1 当前实现

  • Zustand stores。
  • IPC 通道同步。

4.2 Rust 迁移

  • 保持 Zustand。
  • IPC 调用改为 Tauri invoke。

5. 组件库

5.1 设计系统

  • Studio 视觉语言。
  • 暖纸浅色主题 + 匹配深色主题。
  • 设计 tokens。

5.2 核心组件

  • Button, Input, Select, Modal, Toast。
  • Timeline, Block, Card。
  • FileTree, Terminal, Editor。

6. Monaco Editor

6.1 集成

  • 通过 Web Worker 加载。
  • TypeScript/JavaScript 完整代码智能。
  • Python 基础 LSP 支持。

6.2 挑战

  • Tauri WebView 中的 Monaco 集成。
  • 自定义贡献点。
  • 语言服务协议。

7. xterm.js 终端

7.1 集成

  • 通过 WebGL 渲染。
  • PTY 数据流。
  • 块模型解析。

7.2 挑战

  • WebView 性能。
  • 大缓冲区处理。

8. 上下文投喂

8.1 拖拽

  • 文件/文件夹 → 路径引用 chips。
  • @ 打开文件选择器。

8.2 选区

  • 选中代码 → 冻结快照块。
  • 字节随粘贴走。

8.3 外部会话

  • external.injectContext 通道。
  • bracketed paste，不带回车。

9. 性能优化

9.1 虚拟化

  • 大列表虚拟化。
  • 时间线窗口化（400 事件 tail + load-earlier）。

9.2 流式缓冲

  • 大 Agent 输出：256 KB 上限。
  • 超过 16 KB 使用 plain-tail 渲染。

9.3 懒加载

  • 文件树懒加载。
  • 搜索分页。

10. 无障碍

10.1 键盘导航

  • 全局快捷键。
  • Tab 顺序。

10.2 屏幕阅读器

  • ARIA 标签。
  • 语义 HTML。

11. Rust 实现要点

rust
// Tauri 命令
#[tauri::command]
async fn create_task(state: State<'_, AppState>, goal: String) -> Result<TaskId, String> {
    let task = state.task_service.create(goal).await.map_err(|e| e.to_string())?;
    Ok(task.id)
}

#[tauri::command]
async fn list_tasks(state: State<'<'_, AppState>) -> Result<Vec<TaskDto>, String> {
    let tasks = state.task_service.list().await.map_err(|e| e.to_string())?;
    Ok(tasks.into_iter().map(TaskDto::from).collect())
}

// 事件推送
impl AppState {
    fn emit_event(&self, event: AppEvent) {
        let _ = self.app_handle.emit_all("app_event", event);
    }
}
